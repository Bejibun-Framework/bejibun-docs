Bejibun validates request data with **Vine.js**, exposed through `BaseValidator`.
Validators are reusable, type-safe schemas you run against the request payload inside a controller.

## How validation fits together

<Steps>
    <Step title="Define a validator">
        A class extending `BaseValidator` with one schema per action.
    </Step>
    <Step title="Validate the request">
        `request.validate(schema)` runs the validator against the payload and throws on failure.
    </Step>
</Steps>

```ts app/controllers/UserController.ts
await request.validate(UserValidator.store);

// the request payload is now safe to use
```

## What happens on failure

If validation fails, `request.validate()` throws a `ValidatorException` carrying the first failing rule's message.
The [exception handler](/v0.6/guides/core-concepts/error-handling) turns it into a structured error response:

```json
{
    "data": null,
    "message": "The name field must be defined",
    "status": 422
}
```
