Controllers group related request-handling logic into classes. Every Bejibun controller extends **`BaseController`**,
which provides the response builder. Incoming data is read directly from the request via its
[request helpers](/v0.6/guides/http-layer/the-request).

## Creating a controller

Generate one with the `ace` CLI:

```bash
bun ace make:controller HelloController
```

This creates `app/controllers/HelloController.ts`. A minimal controller method receives the request and returns a `Response`:

```ts app/controllers/HelloController.ts
import BaseController from "@bejibun/core/bases/BaseController";

export default class HelloController extends BaseController {
    public async hello(request: Bejibun.Request): Promise<Response> {
        return super.response
            .setData({
                message: "Hello, world!",
                method: request.method
            })
            .send();
    }
}
```

Register the method in a route:

```ts
Router.get("hello", "HelloController@hello");
```

## A complete request flow

The typical controller method reads and validates input, performs work, and returns a response:

```ts app/controllers/TestController.ts
import BaseController from "@bejibun/core/bases/BaseController";
import TestModel from "@/app/models/TestModel";
import TestValidator from "@/app/validators/TestValidator";

export default class TestController extends BaseController {
    public async store(request: Bejibun.Request): Promise<Response> {
        await request.validate(TestValidator.store); // throws ValidatorException on failure

        const test = await TestModel.create({
            name: request.input("name")
        });

        return super.response.setData(test).send();
    }
}
```

- **`request.input(...)`** reads a value from the merged payload (body, params, query, form). See [The Request](/v0.6/guides/http-layer/the-request).
- **`request.validate(...)`** throws a `ValidatorException` on failure (returned as a structured error). See the [validation guide](/v0.6/guides/validation/introduction).
- **`super.response`** builds the standard JSON envelope. See [The Response](/v0.6/guides/http-layer/the-response).

## Resource controllers

Controllers created with `make:controller` include the five resource actions, ready to pair with [`Router.resource`](/v0.6/guides/http-layer/routing#resource-routes):

```ts
import BaseController from "@bejibun/core/bases/BaseController";

export default class TemplateController extends BaseController {
    public async index(request: Bejibun.Request): Promise<Response> {
        // Your code goes here

        return super.response.setData().send();
    }

    public async store(request: Bejibun.Request): Promise<Response> {
        // Your code goes here

        return super.response.setData().send();
    }

    public async show(request: Bejibun.Request): Promise<Response> {
        // Your code goes here

        return super.response.setData().send();
    }

    public async update(request: Bejibun.Request): Promise<Response> {
        // Your code goes here

        return super.response.setData().send();
    }

    public async destroy(request: Bejibun.Request): Promise<Response> {
        // Your code goes here

        return super.response.setData().send();
    }
}
```

## Documenting endpoints

Annotate a controller method with the global `@ApiDoc` decorator to enrich the generated OpenAPI spec:

```ts
@ApiDoc({
    description: "Create a test record",
    request: {
        params: [
            {
                name: "name",
                in: "query",
                required: true,
                schema: {
                    type: "string"
                }
            }
        ]
    }
})
public async store(request: Bejibun.Request): Promise<Response> {
    await request.validate(TestValidator.store);

    const test = await TestModel.create({
        name: request.input("name")
    });

    return super.response.setData(test).send();
}
```

The spec is written to `public/apis.json` and served at `/apis`.
